# ระบบสร้างบันทึกข้อความขออนุมัติค่าบริการโปรแกรม / AI Tools (Memorandum Form)

เว็บแอปพลิเคชันสำหรับสร้างเอกสารบันทึกข้อความทางการตามระเบียบงานสารบรรณ (ฟอนต์ TH Sarabun New, ตราครุฑ, ระยะขอบถูกต้อง) สำหรับการขออนุมัติจัดซื้อ/สมัครสมาชิกโปรแกรมและเครื่องมือ AI

## ฟังก์ชันการใช้งาน
- 📝 ฟอร์มกรอกข้อมูลตามระเบียบงานสารบรรณ พร้อมระบบคำนวณงบประมาณอัตโนมัติ
- 🤖 รวมรายชื่อ AI Tools ยอดนิยม (Claude MAX, Claude Pro, ChatGPT Plus, ChatGPT Team, Perplexity Pro ฯลฯ) พร้อมข้อความเหตุผลความจำเป็นสำเร็จรูปตามระเบียบ
- 🏢 ตัวเลือกฝ่าย/ส่วนงาน และกำหนดชื่อย่อทีมภาษาอังกฤษอัตโนมัติ
- 📄 พรีวิวเอกสารแบบเรียลไทม์ (WYSIWYG) รองรับทั้งแบบ 1 หน้า และ 2 หน้า
- 🖨️ รองรับการสั่งพิมพ์ / บันทึกเป็น PDF ผ่าน Browser Print และ html2pdf
- 📑 รองรับการส่งออกเป็นไฟล์ Microsoft Word (.docx)
- 💾 บันทึกข้อมูลร่างลง LocalStorage อัตโนมัติ ป้องกันข้อมูลสูญหาย

## การใช้งาน
เปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน GitHub Pages
